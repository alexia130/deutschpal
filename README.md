# 🇩🇪 DeutschPal

A modern German vocabulary learning application built with React, TypeScript and Vite.

**Version:** 1.0.0

DeutschPal helps learners organize vocabulary, practice different grammar aspects, track their learning progress and review difficult words through adaptive exercises.

---

## ✨ Features

### 📚 Vocabulary Manager

- Add, edit and delete vocabulary
- Support for:
  - Nouns
  - Verbs
  - Adjectives
  - Expressions
- Favorites
- Search and filters
- Word profile page
- Personal examples

---

### 🧠 Practice Modes

- Meaning
- Articles
- Plurals
- Präteritum
- Perfekt
- Comparative
- Mixed practice
- Context practice

---

### 📖 Verb Trainer

Practice irregular German verbs with dedicated exercises:

- Infinitive
- Meaning
- Präteritum
- Perfekt
- Partizip II
- Auxiliary verb
- Mixed mode

Additional features:

- Pronunciation
- Level filtering
- Letter filtering
- Favorite verbs
- Progress tracking

---

### 📈 Learning Progress

- Knowledge Map
- Learning Timeline
- Mistake History
- Learning Coach
- Adaptive recommendations
- Mastery calculation

---

### 💾 Import & Export

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/deutschpal.git
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

Build production version

```bash
npm run build
```
