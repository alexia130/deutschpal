# DeutschPal

DeutschPal is a modern German vocabulary learning application built with React, TypeScript and Vite.

The application helps learners organize vocabulary, practice different aspects of the German language, monitor learning progress and improve long-term retention through adaptive practice sessions.

---

## Features

### Vocabulary Management

- Add, edit and delete vocabulary
- Support for nouns, verbs, adjectives and expressions
- Favorites
- Search and filtering
- Personal examples
- Word profile page

### Practice

- Meaning practice
- Article practice
- Plural practice
- Präteritum practice
- Perfekt practice
- Comparative practice
- Mixed practice
- Context practice

### Verb Trainer

Dedicated practice mode for German verbs including:

- Infinitive
- Meaning
- Präteritum
- Perfekt
- Partizip II
- Auxiliary verb
- Mixed mode

Additional functionality:

- Pronunciation
- Level filtering
- Initial-letter filtering
- Favorite verbs
- Progress tracking

### Learning Analytics

- Knowledge Map
- Learning Timeline
- Learning Coach
- Mistake history
- Adaptive recommendations
- Word mastery tracking

### Import and Export

- JSON backup
- JSON import
- CSV import
- TSV import
- Automatic duplicate detection
- Vocabulary restore

## Installation

Clone the repository:

```bash
git clone https://github.com/<your-username>/deutschpal.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```
